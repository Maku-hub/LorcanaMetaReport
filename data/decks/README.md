# Local decklists

Drop decklists here and build with `--source local`. Useful for two things:

- running the whole pipeline without crawling anyone's site, and
- mixing in local events that no online platform covers.

Only `.json` and `.txt` files are read, so this README is ignored.

## `.txt` — a pasted list with a small header

Header lines are `key: value`, then a blank line, then the decklist. Every field
except the card list is optional.

```
player: Ada Lovelace
deck_name: Yurple
standing: 3
wins: 5
losses: 2
draws: 0
tournament_name: Kraków Store Championship
tournament_date: 2026-08-12
tournament_players: 34
top_cut: 8
format: Core Constructed

Characters (34)
4 Mulan - Free Spirit
4 Suzy - Master Seamstress
3 Maleficent - Vengeful Sorceress
...

Songs (4)
4 Hold Still
```

`deck_name` is display-only. Archetypes are worked out from card overlap, so the
name you write here never affects how the deck is grouped — see
[`src/lorcana_meta/cluster.py`](../../src/lorcana_meta/cluster.py).

Card lines are tolerant about format: `4 Card`, `4x Card`, `Card x4`, and trailing
set codes or collector numbers (`(TFC) 42`, `[ROF]`, `#57`) are all handled. Section
headers are skipped. A card name has to be the full `Name - Version` form, because
that is how the card database keys them.

## `.json` — one deck, or a list of them

```json
[
  {
    "player": "Ada Lovelace",
    "deck_name": "Yurple",
    "standing": 3,
    "wins": 5,
    "losses": 2,
    "draws": 0,
    "tournament_name": "Kraków Store Championship",
    "tournament_id": "krk-sc-2026-08",
    "tournament_date": "2026-08-12",
    "tournament_players": 34,
    "top_cut": 8,
    "format": "Core Constructed",
    "cards": [
      { "name": "Mulan - Free Spirit", "count": 4 },
      { "name": "Hold Still", "count": 4 }
    ]
  }
]
```

A list with fewer than 40 recognised cards is dropped rather than guessed at — its
card ratios would be misleading. The build logs how many were dropped, and the
site's About page shows the same counts.

## `sample-field.json`

Generated by `python tools/generate_sample_decks.py`. Real card names, invented
decks, players and events; every entry is stamped `SYNTHETIC SAMPLE DATA`. Delete it
once you are pulling real tournaments.
